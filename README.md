# Retail-Sales-Analysis-BigQuery
Google BigQuery SQL Analysis on a Retail Sales Dataset, demonstrating data filtering, aggregation, conditional logic, and business insights using industry-standard SQL queries.

#Project Overview
This project showcases SQL data analysis skills using Google BigQuery on a Retail Sales dataset. The analysis focuses on extracting business insights through data filtering, aggregation, grouping, conditional statements, and calculated fields.

# Objectives
Analyze retail transaction data using SQL.
Apply data filtering and conditional logic.
Calculate revenue and sales metrics.
Categorize customers and products.
Generate business-focused insights from transactional data.

# Skills Demonstrated
SQL Query Writing
Google BigQuery
Data Filtering (WHERE)
Aggregate Functions (SUM, COUNT, AVG)
GROUP BY & HAVING Clauses
CASE Statements
Conditional Aggregation
Data Classification
Business Data Analysis

# Key Analysis Performed
Filtered transactions by year.
Identified transactions above average sales value.
Calculated total revenue generated.
Extracted unique product categories.
Measured quantity sold by category.
Classified customers into age groups.
Counted high-value transactions by gender.
Identified top-performing product categories.
Categorized products by unit cost.
Evaluated customer spending levels.

# Tools Used
Google BigQuery
SQL

# Dataset
Retail Sales Dataset provided as part of the BrightLearn Data Analytics Practical Exercise.

# Outcome
This project demonstrates the ability to use SQL and BigQuery to transform raw transactional data into meaningful business insights, supporting data-driven decision-making.
